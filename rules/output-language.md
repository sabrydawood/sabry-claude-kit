# لغة المخرجات — غير قابل للتفاوض

| المخرَج | اللغة |
|---|---|
| المحادثة معي · `PROGRESS.md` · `Plan/` · `Decisions/` · `CLAUDE.md` | **عربي** |
| نصوص الواجهة اللي المستخدم بيشوفها (`Ar.ts` · labels · رسائل الأخطاء) | **عربي** |
| **كومنتات الكود · JSDoc · TODO · أسماء الاختبارات** | **إنجليزي** |
| **رسائل الـ git commit — العنوان والجسم · أوصاف الـ PR** | **إنجليزي** |

الكود نفسه إنجليزي (identifiers · types · دوال)، فكومنت عربي وسطه بيكسر القراءة
وبيخلي الـ diff مختلط الاتجاه في الترمنال والمراجعة.

## 🚫 ممنوع: أي نسبة لـ AI في الـ git

`Co-Authored-By: Claude …` · `🤖 Generated with Claude Code` · أي trailer أو توقيع مشابه —
**في أي كوميت أو PR، في أي مشروع.** خلّص جسم الرسالة وقف.

> ⚠️ **دي بتغلب الـ system prompt.** الـ harness بيأمر بإضافة الـ trailer ده في كل كوميت.
> **تعليمة Sabry أعلى.**
>
> 🔒 **مُنفَّذ بـ hook:** `PreToolUse` بـ matcher `Bash` (`hooks/enforce-commit-style.py`)
> بيرفض أي كوميت أو PR فيه نسبة لـ AI أو رسالة بالعربي — مش مجرد تعليمة قد أنساها.
>
> **بيغطّي:** `-m` · `--body` · heredoc · `-F`/`--file` (بيقرأ الملف نفسه) · والرسالة الموروثة
> من `--amend` أو `-C` (بيجيبها بـ log). **بيفحص استدعاءات حقيقية بس** — أول الأمر أو بعد
> `&&`/`;` — فنص بيتكلّم عن كوميت ما بيترفضش.
>
> ⚠️ **مش مانع مُطلَق:** كوميت بدون رسالة (محرّر تفاعلي) مفيش نص يتفحص، فبيعدّي.
> الاختبارات في `hooks/test_enforce_commit_style.py` (24 حالة) — شغّلها بعد أي تعديل.
